SANTORI BONUS BUY — СЕРВЕРНЫЙ ВИДЖЕТ ДЛЯ OBS

АДРЕСА

Публичный виджет для OBS:
https://ваш-домен.ru/

Панель управления:
https://ваш-домен.ru/admin

Публичная страница предназначена только для показа. На ней нельзя случайно
изменить данные или удалить бонуску.

Через /admin можно:

• устанавливать номер BONUSBUY#;
• выбирать валюту: RUB, USD, EUR, KZT, UAH или GBP;
• добавлять и удалять бонуски;
• вводить название слота;
• вводить стоимость бонуски;
• вводить результат;
• выбирать текущую бонуску кликом;
• переключать текущую бонуску стрелками вверх и вниз;
• переходить к следующему полю клавишей Enter.

Текущая бонуска отмечается так:
> 1. НАЗВАНИЕ СЛОТА (СТОИМОСТЬ) <

СЕРВЕР

Требуется Node.js 18 или новее.

Перед запуском обязательно задайте:

ADMIN_TOKEN=ваш_сложный_секретный_пароль
PORT=3000

Запуск:

npm start

ADMIN_TOKEN запрашивается при первом открытии /admin и хранится только
в текущей вкладке браузера. Не передавайте этот токен зрителям.

Состояние виджета хранится на сервере в data/state.json. Поэтому админ-панель
и OBS видят одинаковые данные даже на разных компьютерах.

НАСТРОЙКА OBS

1. Добавьте источник «Браузер».
2. В поле URL укажите публичный адрес виджета без /admin.
3. Установите ширину 480.
4. Установите высоту 523.
5. FPS можно оставить 30.
6. Нажмите ПКМ по источнику → «Трансформировать» → «Сбросить трансформацию».
7. Оставьте масштаб источника 100%.

ВАЖНО ДЛЯ ЧЁТКОСТИ

Виджет автоматически вписывается в размер окна браузерного источника,
сохраняет пропорции и центрируется. Размер меняйте только в свойствах
источника «Браузер», а не трансформацией на сцене.

Рекомендуемые размеры:

• основной, максимально чёткий: 480 × 523;
• крупный, максимально чёткий: 960 × 1046.

Эти два размера используют точный масштаб 1× или 2×. Промежуточные размеры
могут давать небольшое сглаживание мелкого текста.

После выбора размера нажмите ПКМ по источнику → «Трансформировать» →
«Сбросить трансформацию». Масштаб источника на сцене должен оставаться 100%.

ПОКАЗАТЕЛИ

Монета — общая стоимость всех бонусок.
Весы — средний X, необходимый на оставшихся бонусках для полного окупа.
Крестик — средний X уже открытых бонусок.
Звезда — количество открытых бонусок относительно общего количества.

Результат 0 считается открытой бонуской, если админ явно ввёл 0 в поле
«Сколько дала».
